# Pastebin Clone

A simple Pastebin clone built with Flask and React. Users can submit text, save it to SQLite, and view it through a unique URL.

## Tools and Frameworks

- Python
- Flask
- Flask-CORS
- SQLite
- React
- Vite
- JavaScript
- npm

## Running the Backend

```bash
pip install flask flask-cors
python app.py
```

## Running the Frontend

Open a second terminal and run:

```bash
cd frontend
npm install
npm run dev
```
